# Package boundary

Experimental overlay only. The original archive remains separate and read-only. This preview adds a title menu and a controller adapter through the original browser input interface, preserves the ordinary proof8 patched engine, and gives assets, caches, BroadcastChannels, runtime attestation and network peers a fresh matching build identity.

The locally built private runtime contains the patched binary for archive testing. The GitHub source bundle contains the patch recipe and rebuild tool, without original/patched engines, captured content, private sessions or test harnesses. Local reconstruction must match both the pinned original and patched hashes.

All final files are checksummed. The served controller/menu/transport and launcher sources are part of the peer shell identity. Source or UI edits require fresh build metadata and checksums. Package verification is separate from gameplay proof.

Retained research evidence remains outside this clean release package. The original private packaging pass made no publication or paid deployment. This public handoff adds preservation documentation and tools; it includes no game payload or prebuilt engine.
